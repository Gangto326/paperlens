## 알려진 실패 조건

파서와 문장 연결:

- GROBID 0.9.1은 일부 문장에서 인용 표시 뒤의 글을 잘라내거나 두 문장을 이어 붙인다(2410.21418에서 4건). 그런 문장은 "불확실" 또는 "연결 실패"로 표시된다. 다른 문장을 대신 보여 주지는 않는다.
- 대시 종류(– 와 -)가 다르면 연결이 "불확실"이 될 수 있다(1건).
- GROBID가 따로 뺀 수식이 문장 안에 있으면 그 수식의 자리표시자를 만들지 못한다(2005.11401에서 2건).
- 감사의 글과 각주가 본문 끝으로 옮겨져 읽기 순서가 원문과 다를 수 있다.

번역과 해설:

- 용어 표기가 용어집과 다르게 나오는 문장이 있다(이번 세대 1건).
- 청크로 돌리면 문장 하나만 돌릴 때보다 해설이 짧다(09-29 관찰).
- 조사 작업 하나가 입력 토큰을 유난히 많이 쓰는 경우가 있다(이번 실행에서 55만, 나머지는 15만~25만). 한도 사용의 대부분은 조사 단계다.
- 긴 논문의 통합 턴에 들어가는 요약 모음이 너무 길 때의 처리가 없다.
- 한 번에 읽는 1차 패스와 통합 턴은 끊기면 처음부터 다시 요청한다. 받던 출력에서 건지지 않는다.
- 1차 패스와 긴 논문의 부분 작업은 요청 하나에 20분까지 기다린다. 넘으면 그 요청은 실패한다.

운영:

- 작업 락은 pid로 판단한다. 앱이 죽은 뒤 같은 pid를 다른 프로그램이 쓰면 `job.lock`을 손으로 지워야 한다.
- 받는 도중의 출력 파일은 전원이 끊기면 마지막 조각이 없을 수 있다.
- GROBID 컨테이너는 메모리를 4GB까지 쓴다. 앱은 Docker를 켜지 않는다.
- 2026-10-01에 점검 화면의 순환 호출로 `docker` 명령이 끝없이 떠 노트북이 멈춘 일이 있었다(유력한 원인). 순환을 끊었고 겹친 점검 호출을 한 번으로 묶는 장치를 넣었다. 장치는 테스트로만 확인했다.

## 지원하지 않는 범위

- 스캔한 PDF(OCR 없음), 암호가 걸린 PDF.
- 표, 그림, 따로 떨어진 수식의 해설. 본문 문장만 다룬다.
- 채팅, 노트, 동기화, 번역본 PDF 내보내기.
- macOS Intel 외의 실행 패키지. 서명과 설치 파일(dmg)도 없다.

## 실제로 확인하지 못한 것

- 52쪽 논문의 완주, 그리고 본문이 25,000토큰을 넘는 논문의 나눠 읽기 뒤 번역.
- 검색 없는 카드 쓰기(`research/concept-cards.ts`)의 실제 모델 실행. 이번 실행에서는 조사가 모든 카드를 채워 돌 일이 없었다.
- 패키지 앱으로 번역을 시작해 끝내는 것. 패키지 앱은 실제 사용자 데이터로 띄워 로그인 상태와 저장된 번역 읽기까지만 보았다.
- 실제 모델 실행 도중의 앱 강제 종료와 재개.
- 회전된 실제 논문의 화면 선택.
- 표본 30개 검토와 출처 근거 대조.
